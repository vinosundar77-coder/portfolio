# Vinothini S — Portfolio

Interactive portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion and Lenis.

## Edit content
All text lives in `src/content/portfolio.ts`. Images and the SNITCH video live in `public/media/`.
To swap an image for a sharper version, replace the file in `public/media/` with the same name.

## Run locally
npm install
npm run dev        # http://localhost:3000

## Deploy on Vercel
1. Put this folder in a GitHub repository.
2. Go to vercel.com → Add New → Project → Import that repository.
3. Leave all settings as detected (Framework: Next.js) and click Deploy.
Every push to the repository redeploys the site automatically.
